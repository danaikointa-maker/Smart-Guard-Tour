📖 Smart Guard Tour — API Docs

สเปกเต็มอยู่ที่ /api/openapi.json (OpenAPI 3) · Realtime ผ่าน WebSocket ที่ /ws?token=...

🔑 การยืนยันตัวตน

ล็อกอิน POST /api/login {name, pin} → ได้ token ส่งเป็น header x-token ทุก request (จำกัด 10 ครั้ง/5 นาที/IP) หรือผ่าน SSO: GET /api/sso/authorize?name=...

🚶 โฟลว์ รปภ.

ขั้นตอนEndpoint
เช็คอิน (สแกน QR)POST /api/guard/checkin {qr}
เริ่มกะ (เริ่ม GPS)POST /api/guard/start {shiftId}
ตำแหน่ง (WS หรือ REST)WS {type:'pos',...} หรือ POST /api/guard/position
ถ่ายรูปเช็คจุด (geofence)POST /api/guard/visit {checkpointId, lat, lng, photo}
แจ้งเหตุการณ์POST /api/guard/incident {type, description, photo}
SOSPOST /api/guard/sos {lat, lng}
ออฟไลน์ซิงก์POST /api/guard/sync {positions[], visits[]}
เช็คเอาต์ (สแกน QR) → รายงานPOST /api/guard/checkout {shiftId, qr}

🖥️ Admin / 🏠 ลูกบ้าน

ดูสเปกเต็มใน openapi.json — admin ตั้งค่าทั้งหมดได้ (ป้อม/จุดตรวจ/ผู้ใช้/เวร/ตั้งค่า/กลุ่มแจ้งเตือน/สถิติ), ลูกบ้านอ่าน GET /api/resident/status ตามสิทธิ์ความเป็นส่วนตัว
