# Smart-Guard-Tour 🛡️

ระบบตรวจตราของ รปภ. — **เช็คอินด้วย QR → เริ่มกะ (GPS อัตโนมัติ) → ถ่ายรูปตามจุดตรวจ → เช็คเอาต์ → รายงานเข้าสู่ส่วนกลางอัตโนมัติ**

##ภาพรวม
- **แอป รปภ.** (`/guard.html`) — มือถือใช้กล้องสแกน QR + GPS ในเครื่อง directly (ดีไซน์ native app ภายหลังได้ตามที่วางไว้)
- **ระบบหลังบ้าน Admin** (`/admin.html`) — ตั้งค่าได้ทั้งหมดจากหน้าเดียว:
  - 🗺️ แผนที่สดแบบเรียลไทม์ (WebSocket) + เส้นทางย้อนหลัง
  - ➕ ป้อม & จุดตรวจ (คลิกแผนที่) · 🎫 พิมพ์ QR · 📋 กะ & รายงานพร้อมรูป
  - 👥 จัดการผู้ใช้ทุกบทบาท (รปภ. / หัวหน้า / ลูกบ้าน / admin) เปลี่ยน PIN ได้
  - 🕐 ตารางเวร (รปภ. @ ป้อม วันไหนกี่โมง) — แอป รปภ. แสดงเวรตัวเองตอนเช็คอิน
  - 🔔 กลุ่มแจ้งเตือนเลือกช่องทางได้จริง: **Telegram** (Bot Token+Chat ID) / **LINE** (Access Token+ID) / Webhook — มีปุ่ม **🧪 ทดสอบส่ง**
  - ⚙️ ตั้งค่าระบบ: ความถี่ GPS, รัศมีเริ่มต้นป้อม/จุดตรวจ, คุณภาพรูป, **สิทธิ์ลูกบ้าน** (เห็นสถานะตรวจได้ / เห็นตำแหน่งสด = ปิดเริ่มต้น / เห็นย้อนหลัง), จุดกึ่งกลางแผนที่
- **บริการกลาง** — REST API + WebSocket + ฐานข้อมูล SQLite แยกของระบบนี้เอง (PostgreSQL+PostGIS ในโปรดักชัน)

เอกสาร: [ออกแบบระบบ](docs/smart-guard-tour-design.md) · [สถาปัตยกรรม เอกสารออกแบบฉบับเต็ม: [`docs/smart-guard-tour-design.md`](docs/smart-guard-tour-design.md) โครงสร้างพัฒนาต่อ](docs/architecture.md)

## 🏢 หลายโครงการ (Multi-site)
Admin แท็บ ➕ มีตัวเลือก **🏢 โครงการ** + ปุ่มเพิ่มโครงการใหม่ — ป้อม/จุดตรวจแยกตามโครงการ, รปภ. จะเห็นเฉพาะจุดของโครงการที่ป้อมนั้นสังกัด · **⏰ ถ้าเช็คอินนอกเวร**ตามตารางเวร แอปจะขึ้นเตือนทันที

## 👥 จุดตรวจแบบ 2 คน (Two-person verification)
Admin เปิด flag "👥 2 คน" ต่อจุดตรวจ (แท็บ ➕ ป้อม & จุดตรวจ) — รปภ. คนแรกเช็คจุดสำคัญจะขึ้นสถานะ **⏳ รอคนที่ 2**; เมื่อ รปภ. อีกคนมาเช็คจุดเดียวกันในรัศมีภายใน 30 นาที → **จับคู่ยืนยันอัตโนมัติ** (ติดในรายงาน/สถิติด้วย)

## 🚨 แจ้งเหตุการณ์จาก รปภ.
แอป รปภ. มีปุ่ม **📢 แจ้งเหตุการณ์** (เลือกประเภท + รายละเอียด + ถ่ายรูป + ตำแหน่ง GPS อัตโนมัติ) → ส่งเฉพาะกลุ่มที่ตั้ง `event_type = incident` (หรือ `incident:<ประเภท>`) ใน 🔔 แจ้งเตือน + เด้งเข้าแผนที่สดของ Admin ทันที + เก็บในแท็บ 📋 รายงาน

## 📊 ฮีตแมป & ส่งออกรายงาน (Admin)
แท็บ 🗺️ แผนที่สดมีปุ่ม **🔥 ฮีตแมปจุดตรวจ**; ในรายงานกด **📥 CSV** หรือ **🖨️ พิมพ์/บันทึก PDF**

## 📶 ประหยัดดาต้าซิมมือถือ (เหมาะ รปภ.ที่อยู่นอกสถานที่)

- GPS จะส่งเมื่อครบเวลา **และ** ขยับเกิน `gps_min_move_m` (ค่าเริ่มต้น 15 ม.) จากจุดก่อนหน้า — ปรับได้ใน ⚙️
- เน็ตขาดก็มีคิวออฟラインซิงก์อัตโนมัติเหมือนเดิม 📴

## 🤖 AI ตรวจรูปอัตโนมัติ (design ข้อ 10 — version เบาๆ ไม่ต้องพึ่งเซิร์ฟเวอร์ ML)
ตอน รปภ. ถ่ายรูปจุดตรวจ ระบบจะวิเคราะห์รูป**ในเครื่องทันที** (canvas): ความสว่างเฉลี่ยต่ำ → `dark` · Laplacian variance ต่ำ → `blurry` · ความละเอียดต่ำ → `lowres` — แจ้งเตือน รปภ. ให้ถ่ายใหม่ถ้ายังทัน และส่ง flag ไปกับรูป (ทั้งทางออนไลน์และคิวออฟไลน์) → หน้า Admin ในรายงานจะแสดงป้าย 🏷️ ต่อจุดที่รูปมีปัญหา

## 🧭 เส้นทางตรวจแบบไดนามิก (dynamic route — design ข้อ 10)
`GET /api/guard/route` คำนวณลำดับจุดตรวจอัตโนมัติจากตำแหน่งปัจจุบันของ รปภ.: **ยังไม่เช็คมาก่อน → boost จุดที่ใกล้เหตุการณ์เปิดอยู่ (<300 ม.) → เรียงจากใกล้ไปไกล** — แอป รปภ. แสดงป้าย 🧭 #ลำดับ และรีเฟรชทุก 15 วินาที

## 📲 NFC แทน/เสริม QR (design ข้อ 10)
แอป รปภ. รองรับ **Web NFC** — แตะการ์ด NFC ที่ป้อมได้เลย ไม่ต้องสแกน QR (มีประโยชน์เมื่อสติกเกอร์ QR เสียหายหรือแสงไม่ดี) · การ์ด NFC เขียนข้อความเดียวกับ QR (`SGT1:P:...`) — ในหน้า Admin กด 📋 คัดลอกรหัส QR แล้วเขียนลงการ์ด (ต้องใช้ Chrome บน Android + HTTPS) · ปุ่ม 📲 จะขึ้นเฉพาะเครื่องที่รองรับ

## 🌐 แดชบอร์ดสาธารณะ (Public Dashboard — design ข้อ 10)
หน้า `/public.html` ไม่ต้องล็อกอิน แสดงภาพรวมสถานะความปลอดภัย: กำลังตรวจกี่กะ, ตรวจครบกี่จุดต่อป้อม (progress bar), เหตุการณ์ที่เปิดอยู่, SOS วันนี้ — **ข้อมูลรวมอย่างเดียว ไม่มีชื่อ รปภ./พิกัด/เส้นทาง** ปิดได้ใน ⚙️ (`public_dashboard`)

## 🌐 Webhooks ภายนอก (API เปิด — เชื่อม VVA / CCTV / ระบบอื่น)
ตั้งค่าในแท็บ 🔔 → การ์ด Webhooks: ใส่ URL + secret + events ที่สนใจ (`sos, incident, incident_resolved, visit, missed_cp, shift, report`) — ระบบ POST JSON ไปพร้อม header ลายเซ็น `X-SGT-Signature: sha256=<HMAC-SHA256(secret, timestamp+"."+body)>` retry 3 ครั้ง และมีหน้า 📜 บันทึกการส่งให้ตรวจสอบย้อนหลัง

## 📴 ออฟไลน์ครบทุกเหตุการณ์ + 🔋 รายงานแบต
ถ้าเน็ตขาดตอนกด **SOS หรือแจ้งเหตุการณ์** ระบบจะเก็บเข้าคิวในเครื่อง (localStorage) แล้วซิงก์อัตโนมัติเมื่อกลับออนไลน์ (`POST /api/guard/sync` รองรับ `sos` + `incidents` ด้วย) — รปภ. แจ้งแบตเครื่องส่งขึ้นเซิร์ฟเวอร์ทุกครั้งที่ส่ง GPS แดชบอร์ดหัวหน้า (`GET /api/admin/guards-status` + WS event `battery`) จะโชว์ 🔋% ต่อกะ สีแดงเมื่อ ≤20%

## 🔔 Web Push (แจ้งเตือนเด้งในเบราว์เซอร์)
หน้า Admin auto-subscribe Push (service worker `sw.js` + VAPID key สร้างอัตโนมัติ) — จะได้รับเด้งทันทีเมื่อมี **SOS / เหตุการณ์ใหม่ / จุดตรวจที่ขาด** แม้ปิดแท็บ; ปุ่ม "🔔 ทดสอบ Push" อยู่ในแท็บแผนที่สด

## 🔐 QR หมดอายุ + session TTL + ปิดกะอัตโนมัติ
ตั้งค่าใน ⚙️: `qr_ttl_hours` (0=ไม่หมดอายุ) → QR เก่าใช้ไม่ได้ (410) + ปุ่ม **🔄 QR ใหม่** ต่อป้อมในแท็บ ➕ · `session_ttl_hours` (เริ่มต้น 12 ชม.) → token หมดอายุต้องล็อกอินใหม่ · ถ้า รปภ. ลืมเช็คเอาต์ ระบบจะ**ปิดกะอัตโนมัติ**หลัง 12 ชม. หรือเลยเวลาสิ้นสุดเวร (เช็คทุกนาที + รันเองได้ `POST /api/admin/auto-close`) · rate limit login นับเฉพาะครั้งที่ผิด (10/5 นาที/IP)

## 📦 สำรอง/กู้คืน + ⏰ บังคับเวร
แท็บ 📊 สถิติมีปุ่ม **📦 ดาวน์โหลดสำรองข้อมูล (JSON ทุกตาราง)** และ **♻️ กู้คืน** · ตั้งค่า `enforce_schedule=true` ใน ⚙️ → รปภ.เช็คอินนอกเวรจะถูกปฏิเสธ (403) · ปุ่ม **📊 ส่งออกสถิติ Excel**

## 🚨 วงจรเหตุการณ์ + 🧹 Retention (PDPA)
เหตุการณ์มีสถานะ open → resolved (admin กด "✔ แก้แล้ว" ในแท็บ 📋, มี realtime broadcast) · ข้อมูล GPS เก่ากว่าที่ตั้งค่า `gps_retention_days` (เริ่มต้น 90 วัน) จะถูกลบอัตโนมัติทุกวัน หรือกดรันเองผ่าน `POST /api/admin/cleanup`

## 🛡️ ความปลอดภัย & เอกสาร API

- เอกสาร API: หน้า `📖 /docs.html` + สเปก OpenAPI ที่ `/api/openapi.json`
- 📅 สรุปรายสัปดาห์อัตโนมัติทุกวันจันทร์ 08:00 น. ส่งเข้ากลุ่มแจ้งเตือน

## 🏭 พร้อมโปรดักชัน
- **SSO จริง (OAuth2/OIDC)**: ตั้ง env `VVA_SSO_AUTH_URL / VVA_SSO_TOKEN_URL / VVA_SSO_USERINFO_URL / VVA_SSO_CLIENT_ID / VVA_SSO_CLIENT_SECRET / SGT_PUBLIC_URL` แล้วปุ่ม SSO จะ redirect ไป VVA จริง (ไม่ตั้ง env = mock)
- **รูปเข้า S3/MinIO**: ตั้ง env `S3_ENDPOINT / S3_BUCKET / S3_REGION / S3_ACCESS_KEY / S3_SECRET_KEY / S3_PUBLIC_URL`
- **PostgreSQL+PostGIS**: `scripts/migrate-to-postgres.sql`
- **Google Maps**: ⚙️ ตั้งค่า `map_provider=google` + `google_maps_api_key`
- **Excel**: ปุ่ม 📊 ในหน้ารายงาน (3 ชีต: สรุป/จุดตรวจ/GPS)

## 🔐 SSO ผ่าน VVA
เปิดใน ⚙️ ตั้งค่า → `sso_enabled = true` แล้วหน้าล็อกอินทุกหน้าจะมีปุ่ม **🔐 เข้าด้วย SSO** — ต้นแบบจำลอง VVA ด้วย signed token (`/api/sso/mock-issue` → `/api/sso/login`, ผูกบัญชีด้วย `vva_user_id`) — โปรดักชันสลับเป็น OAuth2/OIDC จริงได้เลย

## โฟลว์ รปภ. (4 ขั้นตอน)
1. ล็อกอิน → **สแกน QR ที่ป้อม** (หรือพิมพ์รหัส) = เช็คอิน
2. กด **▶ เริ่มปฏิบัติงาน** → ระบบเริ่มรับ GPS อัตโนมัติ ส่งเข้า WebSocket
3. เดินตามจุดตรวจ — แอปโชว์ระยะห่างแบบเรียลไทม์ ปุ่ม **📷 ถ่ายรูป** จะกดได้เมื่ออยู่ในรัศมีจุดนั้น Server ตรวจ geofence (haversine บนทรงกลม) ก่อนยืนยัน — นอกรัศมี = ปฏิเสธ
4. **สแกน QR อีกครั้ง** = จบงาน → สร้างรายงาน (รูป+เวลา+accuracy+จุด GPS) ส่งเข้า Admin แบบเรียลไทม์ + webhook ตามกลุ่มที่ตั้งค่าไว้
