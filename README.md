# Smart-Guard-Tour 🛡️

ระบบตรวจตราของ รปภ. — **เช็คอินด้วย QR → เริ่มกะ (GPS อัตโนมัติ) → ถ่ายรูปตามจุดตรวจ → เช็คเอาต์ → รายงานเข้าสู่ส่วนกลางอัตโนมัติ**

##ภาพรวม
- **แอป รปภ.** (`/guard.html`) — มือถือใช้กล้องสแกน QR + GPS ในเครื่อง directly (ดีไซน์ native app ภายหลังได้ตามที่วางไว้)
- **ระบบหลังบ้าน Admin** (`/admin.html`) — ตั้งค่าได้ทั้งหมดจากหน้าเดียว:
  - 🗺️ แผนที่สดแบบเรียลไทม์ (WebSocket) + เส้นทางย้อนหลัง
  - ➕ ป้อม & จุดตรวจ (คลิกแผนที่) · 🎫 พิมพ์ QR · 📋 กะ & รายงานพร้อมรูป
  - 👥 จัดการผู้ใช้ทุกบทบาท (รปภ. / หัวหน้า / ลูกบ้าน / admin) เปลี่ยน PIN ได้
  - 🕐 ตารางเวร (รปภ. @ ป้อม วันไหนกี่โมง) — แอป รปภ. แสดงเวรตัวเองตอนเช็คอิน
  - 🔔 กลุ่มแจ้งเตือนเลือกช่องทางได้จริง: **Telegram** (Bot Token+Chat ID) / **LINE** (Access Token+ID) / Webhook — มีปุ่ม **🧪 ทดสอบส่ง**
  - ⚙️ ตั้งค่าระบบ: ความถี่ GPS, รัศมีเริ่มต้นป้อม/จุดตรวจ, คุณภาพรูป, **สิทธิ์ลูกบ้าน** (เห็นสถานะตรวจได้ / เห็นตำแหน่งสด = ปิดเริ่มต้น / เห็นย้อนหลัง), จุดกึ่งกลางแผนที่
- **บริการกลาง** — REST API + WebSocket + ฐานข้อมูล SQLite แยกของระบบนี้เอง (PostgreSQL+PostGIS ในโปรดักชัน)

## 🚨 แจ้งเหตุการณ์จาก รปภ.
แอป รปภ. มีปุ่ม **📢 แจ้งเหตุการณ์** (เลือกประเภท + รายละเอียด + ถ่ายรูป + ตำแหน่ง GPS อัตโนมัติ) → ส่งเฉพาะกลุ่มที่ตั้ง `event_type = incident` (หรือ `incident:<ประเภท>`) ใน 🔔 แจ้งเตือน + เด้งเข้าแผนที่สดของ Admin ทันที + เก็บในแท็บ 📋 รายงาน

## 📊 ฮีตแมป & ส่งออกรายงาน (Admin)
แท็บ 🗺️ แผนที่สดมีปุ่ม **🔥 ฮีตแมปจุดตรวจ**; ในรายงานกด **📥 CSV** หรือ **🖨️ พิมพ์/บันทึก PDF**

```bash
docker compose up --build    # เปิดที่ http://localhost:3000
```

## 🔐 SSO ผ่าน VVA
เปิดใน ⚙️ ตั้งค่า → `sso_enabled = true` แล้วหน้าล็อกอินทุกหน้าจะมีปุ่ม **🔐 เข้าด้วย SSO** — ต้นแบบจำลอง VVA ด้วย signed token (`/api/sso/mock-issue` → `/api/sso/login`, ผูกบัญชีด้วย `vva_user_id`) — โปรดักชันสลับเป็น OAuth2/OIDC จริงได้เลย

## โฟลว์ รปภ. (4 ขั้นตอน)
1. ล็อกอิน → **สแกน QR ที่ป้อม** (หรือพิมพ์รหัส) = เช็คอิน
2. กด **▶ เริ่มปฏิบัติงาน** → ระบบเริ่มรับ GPS อัตโนมัติ ส่งเข้า WebSocket
3. เดินตามจุดตรวจ — แอปโชว์ระยะห่างแบบเรียลไทม์ ปุ่ม **📷 ถ่ายรูป** จะกดได้เมื่ออยู่ในรัศมีจุดนั้น Server ตรวจ geofence (haversine บนทรงกลม) ก่อนยืนยัน — นอกรัศมี = ปฏิเสธ
4. **สแกน QR อีกครั้ง** = จบงาน → สร้างรายงาน (รูป+เวลา+accuracy+จุด GPS) ส่งเข้า Admin แบบเรียลไทม์ + webhook ตามกลุ่มที่ตั้งค่าไว้
